# Rubik's Cube Solver

A single-file, animated 3D Rubik's cube solver — pure HTML/JS/Three.js, no build step, no dependencies to install.

**▶ [Live demo](https://az9713.github.io/claude-last-one-percent/)**

Drag to rotate the view. Click **Scramble** for 20 animated random turns, then **Solve** to watch it animate back to solved.

## Files

- `index.html` — the app (also mirrored as `rubiks-cube-solver.html`)
- `DEVELOPMENT_JOURNEY.md` — how this was built end-to-end on <1% weekly Claude usage

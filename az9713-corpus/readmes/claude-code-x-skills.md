# X Automation System

An AI-powered X (Twitter) automation system using Claude Code with browser automation capabilities.

## Workflow Overview

This project demonstrates an end-to-end workflow for understanding video content on X and creating posts about it.

### Video Understanding Workflow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        Video Understanding Workflow                          │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌──────────────┐
    │ User Prompt  │  "understand the video in this post: [URL]"
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │   Navigate   │  Claude navigates to the X post via browser automation
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │   Download   │  yt-dlp downloads the video from X
    │    Video     │  Output: downloads/[video_id].mp4
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │   Extract    │  ffmpeg extracts audio track from video
    │    Audio     │  Output: audio/temp.mp3
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │  Transcribe  │  Whisper converts speech to text
    │    Audio     │  Output: transcripts/temp.txt
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │   Generate   │  Claude analyzes transcript and creates summary
    │   Summary    │  Output: Comprehensive video summary
    └──────────────┘
```

### Posting Workflow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           Posting Workflow                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌──────────────┐
    │ User Request │  "write a summary and post to my X account"
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │    Draft     │  Claude composes post based on video summary
    │    Post      │  Checks character limit (280 chars)
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │    User      │  User reviews draft and says "yes" to approve
    │   Approval   │  (Required - Claude never auto-posts)
    └──────┬───────┘
           │
           ▼
    ┌──────────────┐
    │    Post      │  Claude clicks Post button via browser automation
    │    to X      │  Verifies post appears on profile
    └──────────────┘
```

## Example Session

```
User: "understand the video in this post: https://x.com/user/status/123"

Claude: [Navigates to post]
        [Downloads video with yt-dlp]
        [Extracts audio with ffmpeg]
        [Transcribes with Whisper]

        "Here's what the video covers:
         - Topic 1: ...
         - Topic 2: ...
         - Key takeaways: ..."

User: "write a short summary and post to my X account"

Claude: "Here's a draft post:

         Just watched @user's video about [topic]...

         Should I post this to your X account?"

User: "yes"

Claude: [Posts to X]
        "Posted successfully! You can view it on your profile."
```

## Tools Used

| Tool | Purpose |
|------|---------|
| Claude Code | AI assistant CLI with browser automation |
| Claude-in-Chrome | Browser extension for Chrome control |
| yt-dlp | Video downloading from X |
| ffmpeg | Audio extraction from video |
| Whisper | Speech-to-text transcription |

## Quick Start

1. Open Chrome and log into X.com
2. Run `claude --chrome`
3. Try: `"understand the video in this post: [URL]"`

# Claude Code: 35 Concepts

A complete tutorial series covering every concept a non-coder needs to go from zero to productive with Claude Code — Anthropic's agentic CLI tool that edits files, runs commands, and commits code on your behalf.

Based on the YouTube video **"All 35 Claude Code Concepts Explained for Non Coders"** by Chase AI:
[https://www.youtube.com/watch?v=UAMAAoSPu8o&t=6s](https://www.youtube.com/watch?v=UAMAAoSPu8o&t=6s)

Each concept is substantiated with the official [Anthropic Claude Code documentation](https://code.claude.com/docs/en/overview).

---

## Who this is for

No programming background required. Every concept is explained from first principles, every command is shown exactly as you would type it, and the sections are ordered from "must-know day one" to "power user."

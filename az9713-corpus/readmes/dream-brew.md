# DreamBrew

A multi-agent social simulation where AI agents have conversations and expose their inner thoughts. Watch as three AI characters interact in a coffee shop setting, revealing not just what they say, but what they're really thinking.

## What is DreamBrew?

DreamBrew is an interactive simulation featuring three AI agents:

- **Jack** - A friendly barista at "The Daily Grind" coffee shop
- **Claude** - A thoughtful barista at "Bean There" coffee shop
- **Erica** - A social customer who visits both shops

The unique feature is that you can see each agent's **inner monologue** - their private thoughts that they don't say out loud. This creates fascinating social dynamics as Erica carries information (and gossip) between the two coffee shops.

## Quick Start (5 Minutes)

### Step 1: Install Node.js

If you don't have Node.js installed:

1. Go to https://nodejs.org/
2. Download the "LTS" version (the big green button)
3. Run the installer and follow the prompts
4. Restart your terminal/command prompt after installation

To verify installation, open a terminal and type:
```bash
node --version
```
You should see a version number like `v20.x.x`

### Step 2: Get a Google AI API Key

1. Go to https://aistudio.google.com/apikey
2. Sign in with your Google account
3. Click "Create API Key"
4. Copy the key (it looks like `AIzaSy...`)

### Step 3: Set Up the Project

Open a terminal in the project folder and run:

```bash
# Install dependencies
npm install

# Create your environment file
cp .env.example .env
```

Now open the `.env` file in any text editor and replace `your_gemini_api_key_here` with your actual API key:

```
GOOGLE_AI_API_KEY=AIzaSy...your_actual_key_here
```

### Step 4: Run the Application

```bash
npm run dev
```

You should see:
```
▲ Next.js 16.1.0 (Turbopack)
- Local: http://localhost:3000
```

### Step 5: Open in Browser

Open your web browser and go to: **http://localhost:3000**

You'll see the Agent Dreams interface with a dark theme and controls at the top.

### Step 6: Run Your First Simulation

1. Click **"Start Simulation"**
2. Click **"Step"** to advance one turn
3. Watch the agents interact and read their inner thoughts!

## Troubleshooting

### "GOOGLE_AI_API_KEY not set" warning

Make sure you:
1. Created a `.env` file (not `.env.example`)
2. Added your API key without quotes
3. Restarted the dev server after changing `.env`

### "Failed to start simulation" or "no such table" error

The database wasn't initialized correctly:
1. Stop the dev server (Ctrl+C in terminal)
2. Delete the `data` folder in the project directory
3. Restart with `npm run dev`

The database will be recreated automatically.

### "Failed to execute step" error

This usually means:
- Your API key is invalid or expired
- You've hit the API rate limit (wait a minute and try again)
- Network connection issues

### Port 3000 already in use

Another application is using port 3000. Either:
- Close the other application
- Or run: `npm run dev -- -p 3001` to use port 3001

### Database locked error

On Windows, you may need to:
1. Close all terminal windows
2. Delete the `data` folder manually via File Explorer
3. Open a new terminal and run `npm run dev`

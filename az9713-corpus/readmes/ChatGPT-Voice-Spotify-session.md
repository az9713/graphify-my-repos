# ChatGPT Voice Spotify Session

A documented ChatGPT Voice session in the desktop app, showing how a live voice conversation can guide desktop interaction with Spotify.

## What is included

- A readable HTML session transcript: [spotify-desktop-session-transcript.html](https://az9713.github.io/ChatGPT-Voice-Spotify-session/outputs/spotify-desktop-session-transcript.html) (rendered as a live GitHub Pages page).
- A voice-initiated Spotify action ledger.
- An evidence-bounded interruption log derived from the session transcript.
- A technical account of the desktop-control, Spotify UI inspection, research, and verification workflow.

The transcript records a Spotify DJ exploration, playlist analysis, recommendations for the `California, USA` playlist, and the addition of Eagles' original studio recording of **Tequila Sunrise**. It intentionally omits personal filesystem paths, credentials, tokens, and other sensitive information.

# No Proof Left Behind

A **Claude Code Skill** that transforms terse physics textbook content into comprehensive, research-level tutorials with complete proofs and detailed derivations.

> **All code and documentation in this repository were generated by Claude Code, powered by Claude Opus 4.5.**

## What Is This Project?

Physics textbooks often say things like:
- "The proof is left to the reader"
- "It is easy to show that..."
- "Clearly, we have..."
- "Using equation (1.34), we obtain..."

This project provides a **Claude Code Skill** that automatically identifies these "gaps" and **expands them into complete, step-by-step tutorials** that anyone can follow.

### Key Features

- **Powered by Claude Code Skill**: The `physics-text-to-tutorial` skill automates the expansion process
- **General-Purpose**: Works with any physics/mathematics textbook (Byron & Fuller used as example)
- **Research-Level Depth**: Complete proofs, no hand-waving, every step justified
- **Professional LaTeX Output**: Publication-quality PDF tutorials

## Quick Start (5 Minutes)

**Windows:**
1. Download MiKTeX from https://miktex.org/download
2. Run the installer, accept all defaults
3. Open MiKTeX Console once to let it configure

**Mac:**
```bash
brew install --cask mactex
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install texlive-full
```

The compiled tutorial is ready at:

Open this PDF to see the expanded tutorials.

## How It Works

1. **Input**: Your copy of Byron & Fuller's textbook (PDFs placed in `docs/`)
2. **Processing**: Claude Code reads the textbook, identifies gaps, expands content
3. **Output**: LaTeX files with complete proofs in `output/chapters/`
4. **Result**: Compiled PDF tutorial in `output/main.pdf`

**Important:** The source textbook PDFs are not included in this repository due to copyright. You must provide your own copy of "Mathematics of Classical and Quantum Physics" by Byron & Fuller.

### Gap Detection

The converter identifies these patterns that need expansion:

| Pattern | Example | Action |
|---------|---------|--------|
| "Left to the reader" | "The proof is left as an exercise" | Write complete proof |
| "Clearly" / "Obviously" | "Clearly, this equals zero" | Show why explicitly |
| "Easy to show" | "It is easy to show that..." | Show all steps |
| Equation jumps | Going from A to Z directly | Fill in B through Y |
| "Similarly" | "Similarly for the other cases" | Write out each case |

### Output Quality

Every tutorial section includes:

- **Prerequisites**: What should you already know?
- **Definitions**: Precise mathematical statements

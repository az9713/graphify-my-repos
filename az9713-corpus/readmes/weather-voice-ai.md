# Weather Voice AI

> **Generated by Claude Code with Opus 4.5**

A voice-enabled weather assistant that lets you speak your weather questions and hear responses aloud. Built as a Claude Code skill using the OpenAI Agents SDK.

## Features

- **Voice Input** - Speak your weather questions via microphone (Whisper API)
- **Voice Output** - Hear weather reports spoken aloud (OpenAI TTS)
- **Real-time Data** - Uses web search for current, accurate weather information
- **Text Mode** - Type queries and read responses if you prefer
- **Cross-platform** - Works on Windows, macOS, and Linux

## Quick Demo

```bash
# Text query with voice output
cd .claude/skills/weather-voice
npx tsx src/index.ts "What's the weather in Tokyo?"

# Voice input (speak your question)
npx tsx src/index.ts --mic --duration 6

# Text-only mode (no audio)
npx tsx src/index.ts "Weather in Paris" --text-only
```

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/az9713/weather-voice-ai.git
cd weather-voice-ai
```

### 2. Install dependencies

```bash
cd .claude/skills/weather-voice
npm install
```

### 3. Set your OpenAI API key

**Windows (PowerShell):**
```powershell
$env:OPENAI_API_KEY = "sk-proj-your-key-here"
```

**macOS/Linux:**
```bash
export OPENAI_API_KEY="sk-proj-your-key-here"
```

### 4. Install audio recording tool

**Windows:**
```powershell
winget install ffmpeg
```

**macOS:**
```bash
brew install sox
```

**Linux:**
```bash
sudo apt install alsa-utils
```

### 5. Test it!

```bash
npx tsx src/index.ts "Weather in New York" --text-only
```

## Important Notes

### Latency

This is **not real-time**. Total latency is 15-40 seconds from speaking to hearing the response:
- Recording: 5-8 seconds
- Transcription: 1-3 seconds
- Web search: 3-8 seconds
- TTS generation: 2-4 seconds
- Playback: 5-15 seconds

### Voice Input Workflow

When using with Claude Code CLI, users must **type first** to trigger voice input:
1. Type: "Let me speak my weather question"
2. Claude starts recording
3. Speak when prompted
4. Receive voice + text response

## Technology Stack

- **OpenAI Agents SDK** - AI agent with web search capability
- **OpenAI Whisper API** - Speech-to-text transcription
- **OpenAI TTS API** - Text-to-speech synthesis (gpt-4o-mini-tts)
- **TypeScript** - Type-safe implementation

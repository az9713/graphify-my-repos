# chrome-cdp-agent
# chrome-cdp-agent

A CLI tool to interact with Chrome tabs via the Chrome DevTools Protocol (CDP). Provides a command-based interface for browser automation — navigating pages, clicking elements, filling forms, taking screenshots, inspecting the DOM, monitoring network traffic, and more.

## Features

- **42 CDP commands** — click, type, scroll, screenshot, network monitoring, console access, accessibility audits, performance profiling, and more
- **Tab management** — list, switch, open, and close Chrome tabs
- **DOM inspection** — query elements, extract text, view full HTML, track DOM changes
- **Network tools** — monitor requests, mock APIs, analyze waterfalls
- **Device emulation** — test responsive layouts across screen sizes
- **Cookie management** — read, set, and clear cookies
- **Recording** — capture user interactions for replay

## Prerequisites

Chrome must be running with remote debugging enabled:

```bash
# macOS
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome --remote-debugging-port=9222

# Windows
start chrome --remote-debugging-port=9222

# Linux
google-chrome --remote-debugging-port=9222
```

Or use the included launch scripts in `scripts/`.

## Installation

```bash
npm install
npm run build
```

## Usage

```bash
# List open tabs
node dist/browser.js list

# Navigate to a URL
node dist/browser.js open https://example.com

# Take a screenshot
node dist/browser.js screenshot

# Click an element
node dist/browser.js click "button.submit"

# Type into a field
node dist/browser.js type "input#search" "hello world"

# Get page content
node dist/browser.js content
```

Run `node dist/browser.js --help` for the full command list.

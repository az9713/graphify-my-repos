# linkedin-network-intel
# Network Intelligence

**Transform your LinkedIn network into actionable career intelligence.**

Network Intelligence is a Python command-line tool that analyzes your LinkedIn data export to help you:
- Identify relationships that need attention before they go cold
- Find warm paths to target companies for job searches
- Discover who would make your best references
- Understand your network's unique shape and strengths

Based on [Nate Jones' LinkedIn Network Intelligence methodology](https://www.natejonespr.com/).

---

## Quick Start (5 minutes)

### Step 1: Install Python

You need Python 3.11 or newer. Check if you have it:

```bash
python --version
```

If you see `Python 3.11.x` or higher, you're good. Otherwise, download from [python.org](https://www.python.org/downloads/).

### Step 2: Install Network Intelligence

```bash
# Clone or download this repository
cd linkedin_network_nate

# Install the package
pip install -e .
```

### Step 3: Try Demo Mode (No LinkedIn Data Needed)

```bash
# See what the tool can do with sample data
network-intel demo all
```

### Step 4: Use Your Real Data

1. Go to LinkedIn Settings > Data Privacy > Get a copy of your data
2. Request your data and wait for the email (usually 10-30 minutes)
3. Download and unzip the export
4. Run:

```bash
network-intel import /path/to/your/linkedin/export
network-intel decay
network-intel vouch
```

## What Can Network Intelligence Do?

| Command | What It Does | Why It Matters |
|---------|--------------|----------------|
| `import` | Load your LinkedIn data | First step to analyze your network |
| `decay` | Find fading relationships | Know who to reconnect with |
| `reciprocity` | Show who you owe vs. who owes you | Balance your social capital |
| `vouch` | Rank your best potential references | Prepare for job applications |
| `resurrect` | Find dormant conversations to revive | Easy reconnection opportunities |
| `archetype` | Classify your network type | Understand your networking style |
| `warmpath` | Find paths to target companies | Strategic job search |
| `digest` | Generate weekly action report | Stay on top of relationships |

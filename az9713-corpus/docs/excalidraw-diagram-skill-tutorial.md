## What This Repo Adds

The original skill is a coding-agent skill that generates Excalidraw diagrams
from natural language. This repo documents **how it actually works** — peeling
back the layers that are invisible during normal use:

- How `SKILL.md` is injected into the model's context as a behaviour-changing prompt
- How the `.excalidraw` format is plain JSON written element-by-element
- How headless Chromium and Playwright render that JSON to PNG for visual validation
- How the `exportToSvg` function from `@excalidraw/excalidraw` (fetched via `esm.sh`) does the actual drawing
- Why the render-view-fix loop exists and what it catches

## The Skill's File Structure (from the original repo)

```
excalidraw-diagram-skill/
├── SKILL.md                      ← Design methodology + mandatory workflow
└── references/
    ├── color-palette.md          ← All hex colours, semantic fill/stroke pairs
    ├── element-templates.md      ← JSON skeletons for every element type
    ├── json-schema.md            ← Property reference for every field
    ├── render_excalidraw.py      ← Python/Playwright render script
    └── render_template.html      ← Minimal HTML that calls exportToSvg
```

## The One-Line Summary

The skill is a Markdown file that tells Claude what to think.
The `.excalidraw` file is plain JSON that Claude writes directly.
Chromium renders that JSON to PNG so Claude can see its own output and fix it.
Nothing else is magic.

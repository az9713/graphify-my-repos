# bollinger-noir
# Bollinger Band Analyzer

A full-stack web application for technical analysis of stock prices using Bollinger Bands. Built with Python FastAPI backend and TypeScript/Vite frontend.

![Trading Terminal Noir Theme](docs/images/screenshot.png)

## What is This Application?

This application helps traders and investors analyze stock price movements using **Bollinger Bands**, a popular technical analysis tool. It provides:

- Interactive candlestick charts with Bollinger Band overlays
- Configurable parameters (MA period, standard deviation)
- Signal detection (band crossings, squeeze, expansion)
- Multiple timeframe support (daily, weekly, monthly)
- Zoom and pan functionality for detailed analysis

## Quick Start (5 Minutes)

### Prerequisites

Before you begin, ensure you have:
- **Python 3.10+** installed ([Download Python](https://www.python.org/downloads/))
- **Node.js 18+** installed ([Download Node.js](https://nodejs.org/))
- A modern web browser (Chrome, Firefox, Edge)

### Installation

```bash
# 1. Clone or download this project
cd bollinger-band-analyzer

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Install frontend dependencies
cd frontend
npm install
cd ..
```

### Running the Application

**Terminal 1 - Start the Backend:**
```bash
python -m uvicorn backend.main:app --reload --port 8000
```

**Terminal 2 - Start the Frontend:**
```bash
cd frontend
npm run dev
```

**Open your browser:** http://localhost:3000

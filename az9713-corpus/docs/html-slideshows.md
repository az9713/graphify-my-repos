# Claude Code Slideshow — Prompts

Inspired by the YouTube video **"How I Make My Stunning Slideshows in Claude Code"**
https://www.youtube.com/watch?v=O_g5aE_v71c&t=9s

Exact prompts used to generate each HTML slideshow, in order.

---

## 1. Baseline

> Please make a four slide slideshow. First page is how to make stunning slideshows in cloud code. Second is about the HTML CSS format you use. Third is about interactive features. Fourth is about colors and formatting.

---

## 2. Frontend Design plugin reformat

> Please reformat using the frontend design plugin.

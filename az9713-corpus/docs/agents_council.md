# agents_council
# AI Council - Multi-Agent Decision Making Framework

> Make better decisions by getting multiple AI perspectives on any idea, problem, or question.

## What is AI Council?

AI Council is a decision-making tool that gives you **three different expert perspectives** on any topic:

| Agent | Role | Think of them as... |
|-------|------|---------------------|
| **Optimist Strategist** | Finds opportunities and best outcomes | Your enthusiastic business partner |
| **Devil's Advocate** | Identifies risks and challenges | Your cautious legal advisor |
| **Neutral Analyst** | Provides balanced, factual analysis | Your objective consultant |

Instead of getting one AI opinion, you get a **council of three** that debate and analyze your idea from different angles.

## Why Use AI Council?

- **Avoid blind spots**: One perspective misses things. Three perspectives catch more.
- **Better decisions**: See opportunities AND risks before committing.
- **Documented reasoning**: Every analysis is saved for future reference.
- **Fast insights**: All three agents work simultaneously (in parallel).

## Quick Start (5 minutes)

### Prerequisites

1. **Claude Code CLI** installed on your computer
2. A terminal/command prompt application

### Step 1: Open your terminal

- **Windows**: Press `Win + R`, type `cmd`, press Enter
- **Mac**: Press `Cmd + Space`, type `terminal`, press Enter
- **Linux**: Press `Ctrl + Alt + T`

### Step 2: Navigate to this project folder

```bash
cd path/to/claude_code_council_mark_kashef
```

### Step 3: Start Claude Code

```bash
claude
```

### Step 4: Summon the Council

Type this in Claude Code:

```
Agents Gather - Should I learn Python or JavaScript as my first programming language?
```

### Step 5: Watch the magic

- Three agents will launch simultaneously
- Each will analyze from their unique perspective
- You'll get a final synthesis combining all views

## Example Output

When you ask: *"Agents Gather - Should I start a coffee shop?"*

You'll get analysis like:

**Optimist Strategist**: "Coffee culture is growing, location X has foot traffic, here's how to succeed..."

**Devil's Advocate**: "High failure rate in food service, capital requirements, competition from chains..."

**Neutral Analyst**: "Break-even analysis shows X months, market research indicates Y, key success factors are..."

**Final Verdict**: A balanced recommendation weighing all perspectives.

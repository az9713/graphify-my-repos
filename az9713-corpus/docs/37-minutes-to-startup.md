## How to Launch (10 Minutes)

### Step 1: Deploy Your Website (2 minutes)

**Option A - Drag & Drop (Easiest):**
1. Go to https://app.netlify.com/drop
2. Drag the `website` folder onto the page
3. Your site is live! Copy the URL.

**Option B - Command Line:**
- Windows: Double-click `deploy.bat`
- Mac/Linux: Run `./deploy.sh` in terminal

### Step 2: Set Up Payments (5 minutes)

1. Go to https://gumroad.com and create a free account
2. Click "New Product" > "Digital Product"
3. Upload the `products.zip` file (created by deploy script) or manually zip the products folder
4. Set product name: "Ultimate Life Organization Bundle"
5. Set price: $39
6. Click "Publish"

### Step 3: Connect Payments to Site (3 minutes)

1. After publishing on Gumroad, copy your product ID (it's in the URL: `gumroad.com/l/YOUR_PRODUCT_ID`)
2. Open `website/js/checkout.js` in any text editor
3. Find: `GUMROAD_PRODUCT_ID = 'YOUR_GUMROAD_PRODUCT_ID'`
4. Replace `YOUR_GUMROAD_PRODUCT_ID` with your actual ID
5. Save the file
6. Re-deploy your website (drag & drop again)
